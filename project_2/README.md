# Page Theme Changer

A simple Manifest V3 Chrome extension that changes the active webpage's background and text colors.

## Features

- Apply a dark theme to the active page.
- Apply a light theme to the active page.

## Installation

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `project_2` folder.

## Usage

Open a webpage, click the extension icon, and choose Dark Mode or Light Mode.

## Permissions

- `activeTab`: identifies the selected tab.
- `scripting`: executes theme changes on the active webpage.
