# Website Analyzer

A Manifest V3 Chrome extension that inspects information from the active webpage and presents it in a popup.

## Installation

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `P3_Web_analyzer` folder.

## Usage

Open a webpage, click the extension icon, and use the popup controls to analyze the current page.

## Permissions

- `activeTab`: identifies the active browser tab.
- `scripting`: runs analysis code in the active webpage.
