# Live CSS Inspector

A Chrome Manifest V3 extension for hovering over, inspecting, and editing a webpage element in place.

## Features

- Hover outline for page elements.
- Click to lock onto an element.
- Displays the element tag, size, selector hint, and common computed properties.
- Live CSS textarea with Apply, Reset, Copy CSS, and Close actions.
- Shadow-DOM overlay that avoids changing the inspected page's layout.

## Use

1. Open Chrome Extensions and enable Developer mode.
2. Load this folder with **Load unpacked**.
3. Open a normal HTTP or HTTPS page.
4. Click the extension icon and choose **Start Inspector**.
5. Hover, click an element, edit CSS, and choose **Apply**.

Press `Esc` to stop inspection.
