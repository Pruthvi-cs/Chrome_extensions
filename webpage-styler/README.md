# Webpage Styler

A Manifest V3 Chrome extension that adds quick visual controls to the current webpage.

## Features

- Toggle a dark-mode filter on the active webpage.
- Highlight `h1`, `h2`, and `h3` headings.
- Inject styles only into the selected browser tab.

## Installation

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `webpage-styler` folder.

## Usage

Open a normal HTTP or HTTPS page, click the extension icon, and select one of the available styling controls.

## Permissions

- `activeTab`: identifies the active tab.
- `scripting`: applies temporary styles to the active webpage.

## Reloading

After changing an extension file, open `chrome://extensions` and click **Reload** on this extension.
