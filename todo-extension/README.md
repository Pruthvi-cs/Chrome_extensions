# My Todo

A Manifest V3 Chrome extension for storing and managing a simple task list.

## Features

- Add tasks.
- Mark tasks as complete or incomplete.
- Delete tasks.
- Save tasks with `chrome.storage.local`.
- Submit a task by pressing Enter.

## Installation

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `todo-extension` folder.

## Usage

Click the extension icon, enter a task, and click the add button or press Enter.

## Permissions

- `storage`: persists the task list in Chrome.
