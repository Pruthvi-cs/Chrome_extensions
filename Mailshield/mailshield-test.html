Important security limitation
This tool parses pasted text only. Header values, including Authentication-Results, may be forged. A sender-domain mismatch or unusual Received field does not prove phishing. This page does not verify SPF, DKIM, DMARC, message signatures, IP ownership, DNS records, server identity, or the authenticity of the receiving mail system. Received-header analysis is a preliminary review aid, not a security verdict.
