Important security limitation
This tool parses pasted text only. Header values, including Authentication-Results, can be forged in untrusted data. A From/Reply-To/Return-Path domain difference is not proof of phishing. This tool does not verify SPF, DKIM, DMARC, message signatures, or the authenticity of the receiving mail server.
